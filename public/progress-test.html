首次使用与测试说明

请在 Safari、Chrome 等浏览器中打开本页的 HTTPS 地址，不要使用聊天或文件预览。

  1. 在测试项目的 Authentication → Users → Add user → Create new user 中，创建你自己的测试登录账号，设置独立密码；仅对自己控制的邮箱勾选 Auto Confirm User。不要把密码发到聊天中。
  2. 这是学习测试账号，不是 Supabase 管理后台的密码。没有开放注册入口。
  3. 两个设备使用同一个测试账号。A 保存后，B 点击“读取云端”，检查状态、备注和完成时间。
  4. 断网后保存应显示“未确认同步”；联网后先读取云端再判断是否重试。

测试会话仅保存在当前页面内存中，刷新后需重新登录。无自动后台同步。切换为未完成会清除完成时间；不同设备修改同一旧版本会提示冲突。

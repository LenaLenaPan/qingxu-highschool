弱项 1高频失分点

含参数方程：第一步不是判别式

只要参数出现在最高次项系数前，先问：它会不会变成一次方程、常数方程，甚至恒等式？

参数：先分“最高次项系数 = 0”和“最高次项系数 ≠ 0”，再分别处理。

例题

集合 A＝{x｜(m−2)x²＋2x＋1＝0} 恰有一个元素，求 m。

  1. 先查退化：m＝2 时，方程变成 2x＋1＝0，只有一个实根，符合。
  2. 再查二次：m≠2 时，要有两个相同实根，所以 Δ＝2²−4(m−2)＝0。
  3. 解得 m＝3。
  4. 结论：m＝2 或 m＝3。
三秒自检：看到参数方程先问什么？
最高次项系数能否为 0？为 0 后是什么方程？不为 0 时，才可以直接使用判别式或根与系数关系。
弱项 2对象识别

先看集合里的“元素”究竟是什么

P＝{y｜y＝x²−1}

元素是数 y，所以 P 是值域：

P＝[−1，＋∞)
M＝{(x，y)｜y＝x²−1}

元素是有序数对 (x，y)，所以 M 是图像上的点集。

例如 Q＝{y｜y＝−x²＋3}＝(−∞，3]，那么 P∩Q＝[−1，3]；但若两个集合的元素是 (x，y)，就要联立方程求交点。

防错口令
先圈元素：{y｜…} 圈 y；{x｜…} 圈 x；{(x，y)｜…} 圈 (x，y)。没有确认元素类型，不开始计算。
弱项 3计数

子集计数：先分“必选”和“自由”

含 n 个元素的集合：子集共 2ⁿ 个，真子集共 2ⁿ−1 个。

带条件时，不要一上来把所有子集乱列。先标出：

  • 必选元素：题目明确要求一定包含；
  • 禁止元素：题目明确不能包含；
  • 自由元素：每个都有“选或不选”两种可能。

例题

A⊆{1，2，3，4}，A中恰有一个奇数，并且2∈A。奇数从1、3中任选一个，有2种；4可选可不选，有2种。因此共有 2×2＝4 个。

易混点：空集算不算？
空集是任何集合的子集。若题目说“真子集”，空集通常仍要计算；只需排除集合本身。
弱项 4逻辑方向

命题真假，与“是不是命题”是两件事

句子是不是命题真假
3＞π是，有确定真假假命题
x＋1＞0不是，x 未确定暂时不能判断
2是质数吗？不是，这是疑问句不讨论真假

充分必要条件只做两次箭头检查

箭头结果A是B的条件
A⇒B，B⇏A充分非必要
A⇏B，B⇒A必要非充分
A⇒B，B⇒A充要
A⇏B，B⇏A既不充分也不必要

反例要承担任务：要否定 A⇒B，就找一个“A真、B假”的例子；不能只写一个无关数字。

弱项 5证明闭环

证明题不能停在“我看出规律了”

反证法和一般性证明都要写到逻辑终点。建议每次检查四句话是否齐全：

  1. 假设：明确写出原命题结论的否定。
  2. 推导：只使用已知条件和可靠结论。
  3. 矛盾：指出与哪条已知、定义或假设矛盾。
  4. 收口：因此反设不成立，所以原命题成立。

例题：证明不存在整数 n，使 n²＝4k＋2

假设存在整数 n、k 使 n²＝4k＋2。整数 n 只有奇、偶两种：

  • 若 n 为偶数，则 n² 能被4整除；
  • 若 n 为奇数，则 n² 除以4余1。

但4k＋2除以4余2，两种情况都不可能，产生矛盾。因此不存在这样的整数 n。

写出“矛盾在哪里”以后，还要补最后一句结论。

做题前的五项检查

  • □ 集合元素是数，还是有序数对？
  • □ 参数会不会让最高次项消失？
  • □ 空集是否也满足包含关系？
  • □ 区间端点是开还是闭？
  • □ 两个逻辑方向是否分别验证？
  • □ 证明是否写出矛盾和最终结论？

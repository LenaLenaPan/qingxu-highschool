01 / 先确定“谁”，再确定“什么量”

原作答把氢原子的个数填入要求“mol”的空格。问题不是不会乘2，而是粒子个数N与物质的量n混用。

量符号与单位水的例子
质量m / g1 mol水的质量为18 g
物质的量n / mol水分子为1 mol
粒子数N / 计数用“个”水分子约6.02×10²³个
摩尔质量M / g·mol⁻¹水为18 g·mol⁻¹，与取多少水无关

相对分子质量没有g·mol⁻¹这样的单位；摩尔质量有单位。H₂SO₄的相对分子质量约为98，摩尔质量约为98 g·mol⁻¹。

n = m ÷ M　　N = n × Nₐ
Nₐ ≈ 6.02×10²³ mol⁻¹

对于1 mol H₂O：每个水分子含2个氢原子，因此n(H原子)=2 mol；再乘Nₐ，才得到N(H原子)≈1.204×10²⁴个。氧原子则为1 mol，约6.02×10²³个。

解题三问：①对象是分子、原子还是离子？②求n、N、m还是M？③答案单位与空格一致吗？
停一下：2 mol水的摩尔质量是1 mol水的两倍吗？

不是。两者的摩尔质量都是18 g·mol⁻¹；加倍的是总质量、分子数和原子总数。

再检查：等质量H₂SO₄与H₃PO₄，分子数和原子数都相同吗？

两者摩尔质量都按98 g·mol⁻¹计，因此分子数相同。但每个分子分别有7、8个原子，原子总数之比为7∶8。

概念核查 · 第1页第2题（3）

02 / “正盐”不等于“中性溶液”

在KCl、NaHSO₄、K₂CO₃、KNO₃中，按盐的组成分类，NaHSO₄是酸式盐，其余是正盐。

分类角度判断内容例子
盐的组成正盐、酸式盐K₂CO₃是正盐
水溶液性质酸性、碱性、中性K₂CO₃水溶液呈碱性

分类必须统一标准。“NaHSO₄为酸性，其余为中性”不是正确理由。此处暂不要求解释盐类水解，只需先区分两个分类角度。

第2页第5、6题

03 / 看清电荷属于谁

胶体是分散系，分散质粒子直径约为1—100 nm。胶体粒子可以带电，但整份胶体通常呈电中性。同种胶体粒子带同号电荷、相互排斥，是其相对稳定的原因之一。

向阴极移动 → 胶体粒子带正电
向阳极移动 → 胶体粒子带负电

例一：土壤吸附化肥

题设土壤胶体粒子带负电，易吸附NH₄⁺等正离子。NH₄NO₃中一半氮在NH₄⁺中，另一半在NO₃⁻中；(NH₄)₂SO₄中的氮全部在NH₄⁺中。在含氮总量相等、只按题设吸附机制比较时，NH₄NO₃的氮较难全部被吸附保留。不能把这个结论直接扩展为实际施肥建议。

例二：未知正电胶粒的聚沉

加入Fe(OH)₃胶体，两种胶粒均带正电，按本题模型不发生聚沉；加入负电的硅酸胶体，可能聚沉；加入MgSO₄溶液，其中SO₄²⁻可削弱胶粒的电性稳定作用，促使聚沉。

盐溶液里同时有正、负离子。不能只看到Mg²⁺与胶粒同号，就断言不会聚沉。实际聚沉还与浓度等条件有关。
停一下：过滤能代替渗析除去胶体中的盐吗？

不能。常规教材模型中，胶粒能通过普通滤纸，不能通过合适的半透膜；小离子可以通过半透膜。淀粉—NaCl混合体系渗析时，淀粉留在袋内，Na⁺、Cl⁻可向外扩散；一次静置不等于袋内盐已全部除尽。

漏答核查 · 第3页AgCl胶体实验

04 / 一道题问两件事，要答两段

原作答写出了丁达尔现象的检验，但“为什么要用稀溶液”仍需补答。

为什么用稀溶液？在该制备条件下，有利于控制颗粒形成和聚集，避免形成较大的沉淀颗粒，获得胶体分散系。不是“只要浓度低就必然形成胶体”。

如何检验？让一束光通过所得分散系，从侧面观察；若有明显光路，说明出现丁达尔现象，可作为本实验中形成胶体的判断依据。

NaCl + AgNO₃ → NaNO₃ + AgCl（胶体）

胶体与悬浊液的区别在分散质粒径，而不是“AgCl这种物质只能形成哪一种分散系”。

05 / 方程式是计算的起点

原式漏了CO₂前的系数，氧气系数随之出错，后续3 mol、96 g都是连带错误。先配平，才能用系数比计算物质的量。

C₂H₈N₂ + 4O₂ → 2CO₂ + N₂ + 4H₂O（点燃）

检查顺序：C为2 → CO₂前填2；H为8 → H₂O前填4；N为2 → N₂前填1；产物共有8个O原子 → O₂前填4。

60 g C₂H₈N₂对应1 mol。由系数比1∶4，消耗O₂为4 mol、128 g，氧分子约2.408×10²⁴个。

方程式系数比 = 物质的量之比，不是质量之比。算完用原子守恒和单位各检查一次。
第5—6页气体判断题

06 / 22.4前面有条件，后面有单位

标准状况下，气体的Vₘ ≈ 22.4 L·mol⁻¹
V = n × Vₘ　　n = V ÷ Vₘ

本册标准状况指0 ℃、约101 kPa。使用前检查：①是否为气体；②温度、压强是否满足条件；③mL是否换成L。

表述辨析
标准状况下1 mol水占22.4 L错误：该条件下水不是气体
气体摩尔体积为22.4 L单位错误：应为L·mol⁻¹，且需说明条件
标准状况下0.7 mol N₂与0.3 mol O₂占约22.4 L正确：不反应的混合气体总量为1 mol
22.4 L气体的分子数一定更多缺少比较条件：同温同压才可直接按体积比较

同温同压、按理想气体近似：体积比=物质的量比=分子数比。分子数相同不代表原子总数或质量相同。

已有订正，需独立复测 · 第7页第11题

07 / 综合题只做三次转换

已知XY₂(l)+3O₂(g) → XO₂(g)+2YO₂(g)，生成气体在标准状况下共672 mL，密度为2.56 g·L⁻¹。

  1. 体积 → 物质的量：n(生成气体)=0.672÷22.4=0.0300 mol。产物系数和为3，故n(XY₂)=0.0100 mol，n(O₂)=0.0300 mol，V(O₂)=672 mL。
  2. 密度 → 总质量 → 反应物质量：m(产物)=2.56×0.672=1.72032 g；m(O₂)=0.0300×32=0.960 g；由质量守恒，m(XY₂)=0.76032 g。
  3. 质量与物质的量 → 摩尔质量：M(XY₂)=0.76032÷0.0100≈76.0 g·mol⁻¹。若X、Y元素质量比为3∶16，则Aᵣ(X)∶2Aᵣ(Y)=3∶16，得X为C、Y为S。
保留中间数减少舍入误差，最终结果按题目精度处理。求n时应写“体积÷摩尔体积”，不能结果正确却把算式写成乘法。

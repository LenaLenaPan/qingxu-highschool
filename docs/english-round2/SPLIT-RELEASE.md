- 主线 Day32–71，共40次、2400题。每卷20词义、15搭配、13语境、7词形、5翻译，100分。36次词段训练覆盖印刷页1–92的复习安排；4次综合验收。测试是重点抽查，不是5000词逐词测试。
- 历史错题6组，每组10题，独立计分。59道去重变式映射67条待复测或疑似输入失误事件，另1道已编历史变式补足组卷。
- 错题入口按已完成记录整理错误、不确定、待核验项目；自动选取已有题库中的不同题目，不调用AI实时出题。缺变式明确显示“待补变式”。
- 最新错误后至少2天第一次通过，再至少5天第二次通过；均须不同题目、未查词、无不确定标记。两次通过转30天低频抽查。过早做过的题目也不再冒充未见变式。
- 云端仅查询当前登录用户的记录；加载失败显示错误，不显示“没有错题”。登录后不自动合并设备上其他账号的本机记录。动态卷把题目配置保存进草稿，供恢复同一试卷。
- 首答和订正分开，争议标记不改原分；翻译由学生按要点自评。系统归集不等于已经完成教师/AI错因诊断。

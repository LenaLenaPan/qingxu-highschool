## 使用与后续

打开 public/english/round2/index.html，先做Day32。每套70题，100分主卷加10分复测。全部首答后提交；翻译按首答自评；支持本机恢复、TXT和完整JSON导出。尚未搭建自动读历史作答或自动生成新题的后台。

首批复测为根据已有记录编写的初始版；提交Day32结果后，后续页可按实际错误更新。缺失报告可用原有复制总结或下载TXT补充。未找回报告的范围仍通过词表复习覆盖，但不能把抽测当作历史错题回收。

不执行npm构建、不推送main、不触发部署。当前成果先在本地源码保存。
